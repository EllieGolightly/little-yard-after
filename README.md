# 小院之后

一个自己慢慢玩的末日宅家经营小游戏。有限预算、34 件商品、一栋带院子的房子。从采购开始，种菜养殖、做饭配餐，把日子经营成长久的生活。奶油色与鼠尾草绿的小院界面沿用第一版。

## 手机和在线试玩

打开 https://EllieGolightly.github.io/little-yard-after/ 。

- iPhone：用 Safari 打开 → 分享 → 添加到主屏幕 → 添加。
- 安卓：用 Chrome 打开 → 浏览器菜单 → 安装应用 / 添加到主屏幕。
- 游戏「存档与设置」中可查看离线准备状态。首次联网打开并完成缓存后即可离线游玩；新版准备好后，关闭所有小院窗口再重新打开更新。
- 存档保存在当前设备、浏览器或已安装应用里，不会上传 GitHub。电脑存档不会自动出现在手机上，可用导出 / 导入转移。网站更新不会主动删除存档。

## 开始玩

浏览器打开 **outputs/小院之后.html**，无需联网或安装。修改源码后执行 `npm run build` 更新离线版。`outputs/小院之后-v1备份.html` 保留上一版。

开发预览：Mac 双击 **启动小院.command**，保持终端窗口运行；或执行 `npm run dev`，打开 `http://127.0.0.1:4173`。需要 Node.js 20 或以上，无第三方依赖。根目录 index.html 用于开发，双击试玩请用 outputs 里的文件。

## 新的一局

- 安心囤货：¥50,000；精打细算：¥30,000；紧日子：¥20,000。
- 应急援助可独立开关，紧日子默认关闭。食水不足时主动申请，使用会计入记录；不会自动吃饭或自动救活。
- 先平安度过 **30 天**，完成后可继续无尽经营；另有收获、做饭、繁育、连续无援助的小目标。健康降至 0 时暂停本局，开启援助的局可主动休养继续。
- 采购没有倒计时，每档都有预算内基础清单。关门后停止采购，剩余钱保留；可用材料扩建菜地、圈舍与鱼池。

## 每一天

1. 照看成熟的菜地，收获并播种。自动浇水与喂养默认开启，也可改为亲自照料，每日不会重复结算。
2. 到 **今日餐桌** 做饭、选食物和份量。支持 0、半份、四分之一份及两位小数；安排的食物在日结时扣除。可一键搭配或沿用昨天。
3. 两用灶台默认优先用电，不够时用燃料；也可指定能源。菜谱显示每锅的食材、能源、精力及成品。熟食可分份食用，预留在餐桌上的食物不会被烹饪或保存挪用。
4. 自家鸡鸭的种蛋可以吃，也可孵化。鸡鸭需公母种禽；鱼需至少 2 条成鱼。幼崽固定照料天数后长大，容量与食水需求随种群改变。处理成年禽类、捕捞可获得食材；确认前会提示能否继续繁育。
5. 精力用于播种、收获、烹饪、繁育和建设。每日可休息、读书、整理储物间、回收材料或扩建，每项每天一次。回收材料一共 8 次；种植箱最多 4 块，圈舍和鱼池各可扩建两次。
6. 点击 **过完这一天** 才推进时间。默认不会替你安排餐食；餐桌食量不足会先提醒。日结弹窗列出健康、精力和物资变化。

## 主要规则

- 食量 100% 是正常每日需求；每种食品提供不同食量。缺食扣健康，吃饱及丰富搭配恢复健康；过量进食不会无限提升恢复。休息、读书也有恢复作用。健康和精力上限均为 100。
- 个人饮水每日 4 L，炎热天 6 L，有遮阳设施降回 4 L。缺水额外扣健康。生产照料会先预留个人饮水。
- 天气固定 12 天循环，预报显示 3 天，无隐藏随机死亡。日结：补水与发电 → 冰箱和照明 → 自动照料 → 所选餐食与饮水 → 鲜食损耗 → 天数与目标。
- 种植收获返种；温室提前 1 天成熟，堆肥增产 2 份，留种工具额外返种。饲料草可以持续供给养殖，不必只靠采购饲料。
- 鸡蛋每 2 个照料日产出，鸭蛋每 3 日产出。鸡种蛋 6 天出壳、幼鸡 8 天成年；鸭分别 8 / 10 天。孵化批次尽量均分雌雄，奇数多一只母禽。鱼苗每批 4 条，6 天成年。
- 缺水或缺饲料会暂停生产、成长与孵化；资源补足后继续。繁育本身需主动安排，避免动物无限增长。
- 冰箱每晚耗电 1.2 kWh，有电则鲜食当天不损耗。未保鲜的第 4、8、12…天，各类鲜食损耗 25%，至少 0.25 份且不超过库存；整理期间比例降到 10%。鲜食也可用灶台加工为耐储食品。

关页或离线不会推进时间。进度保存在当前浏览器 localStorage，有一份轮换备份。不同设备、浏览器、网址各有自己的存档，不自动云同步，可用设置里的 JSON 导入 / 导出。购物袋未结算的选择不保存。v1 存档可自动升级；首次升级写入前另留一份旧数据。

## 代码与验证

| 文件 | 职责 |
| --- | --- |
| `src/data.js` | 商品、作物、天气、难度、食品、菜谱、活动与基础清单 |
| `src/engine.js` | 独立于界面的规则、结算、动作、校验与迁移 |
| `src/legacy.js` | v1 存档校验 |
| `src/storage.js` | 保存、备份恢复、导入与导出 |
| `src/scene.js` | 随设施、作物与种群变化的 SVG 小院 |
| `src/life.js` | 开局、餐桌、养殖、每日安排与目标面板 |
| `src/app.js` | 页面组合、交互、购物袋与日结弹窗 |
| `src/styles.css` | 桌面、平板与手机样式 |
| `tests/` | 资源消耗、繁育、餐桌、存档与长期经营检查 |

规则与界面分离，可继续增加事件、角色和其他机制。存档结构升级时保持版本迁移。

```sh
npm test
npm run build
```

构建产物包括 `dist/` 静态网页与 `outputs/小院之后.html` 单文件版。没有后端、账户、外部字体或外部图片请求。

## GitHub Pages 发布

推送 `main` 后，GitHub Actions 自动执行游戏测试、构建和 PWA 检查，再发布 `dist/`。仓库 Settings → Pages → Source 选择 GitHub Actions。

```sh
npm test
npm run build
npm run test:pwa
npm run preview
```

预览地址使用 `/little-yard-after/` 子路径验证项目站点与 Service Worker。离线缓存按构建内容生成版本号，只清理本应用同一作用域的旧缓存，不清理浏览器存档或其他应用。
